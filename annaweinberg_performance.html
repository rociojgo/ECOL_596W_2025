Basic Uses of the Performance Package

The performance package allows you to evaluate a model’s performance and fit. The first step is to install the performance package (no other packages explicitly required to use the performance package)

install.packages("performance", repos = "http://cran.us.r-project.org")

Loading data sets

First, install these data sets. Then, some light house cleaning to get the data ready:

larvae_growth= read.csv("larvae_growth_copy.csv", header = TRUE)
fecundity=read.csv("fecundity.csv", header = TRUE)

fecundity$block <- as.factor(fecundity$block)
fecundity$treatment <- as.factor(fecundity$treatment)
larvae_growth$treatment <- as.factor(larvae_growth$treatment)
larvae_growth$larvae_batch <- as.factor(larvae_growth$larvae_batch)
larvae_growth$neonic_level <- as.factor(larvae_growth$neonic_level)
fecundity <- fecundity |> mutate(total_mass=abd_mass+egg_mass)
fecundity <- fecundity |> mutate(egg_total_ratio=egg_mass/total_mass)

check_model() function

In the fecundity data set, let’s look at the distribution of the egg mass to total body ratio (we’re working with butterflies)

hist(fecundity$egg_total_ratio)

Looks pretty normal, so I’ll try a linear model

eggtotal_ratio_model = lm(egg_total_ratio ~ treatment + pre_weight + block, data=fecundity)

check_model(eggtotal_ratio_model)

That looks like a decently well-fitted model! Now, let’s look at a poorly fitted model and what the check_model output gives us using data on the effect of a neonic (pesticide) on early egg mass in the larval growth data set.

gr_early <- larvae_growth[larvae_growth$larvae_batch=="Early",]
ggplot(gr_early, aes(x=neonic_level, y=egg_mass, fill=neonic_level)) + geom_boxplot() + stat_summary(fun = mean, geom = "point", shape = 4, size = 5) +geom_point() +
  labs(x="Neonic Level", y="Egg Mass (mg)", title = "Effect of Neonic on Egg Mass", fill = "Neonic Level") + theme(text = element_text(size = 18))
lm(egg_mass~neonic_level, data=gr_early) %>% check_model()

It doesn’t look great…there’s an outlier at index 17 (shown in red), which you can see on the graph as a datapoint in the 30ppb group way smaller than the mean. Additionally, linearity and normality of residuals look pretty poor. Let’s try without that outlier

gr_early_removedoutliers <- gr_early[-c(17), ]
lm(egg_mass~neonic_level, data=gr_early_removedoutliers) %>% check_model()

Everything looks way better now. Let’s also try plotting again to visualize. Fun fact: without that outlier (which may be a data collection error), there is a significant difference in average egg mass between the two treatment groups!

ggplot(gr_early_removedoutliers, aes(x=neonic_level, y=egg_mass, fill=neonic_level)) + geom_boxplot() + stat_summary(fun = mean, geom = "point", shape = 4, size = 5) +geom_point() +
  labs(x="Neonic Level", y="Egg Mass (mg)", title = "Effect of Neonic on Egg Mass", fill = "Neonic Level") + theme(text = element_text(size = 18))

check_heteroskedasticity()

Now let’s try some other functions, like checking heteroskedasticity with check_heteroskedasticity()

check_heteroscedasticity(lm(egg_mass~neonic_level, data=gr_early))
Warning: Heteroscedasticity (non-constant error variance) detected (p = 0.025).

Heteroskedasticity detected! Now with the outlier removed…

check_heteroscedasticity(lm(egg_mass~neonic_level, data=gr_early_removedoutliers))
OK: Error variance appears to be homoscedastic (p = 0.928).

No longer heteroskedastic

check_zeroinflation()

Finally, let’s go back to everyone’s favorite…euc data! For that age-old question: was the data zero-inflated? The question I was interested in was if there was an effect of native versus exotic grasses on euc recruitment.

euc <- read.csv("datasets/Euc_data.csv", header=TRUE)
check_zeroinflation(glmer(euc_sdlgs0_50cm~NativePerennialGrass_cover+ExoticAnnualGrass_cover+ExoticPerennialGrass_cover+(1|Property), family = "poisson", data=euc))
# Check for zero-inflation

   Observed zeros: 309
  Predicted zeros: 250
            Ratio: 0.81
Model is underfitting zeros (probable zero-inflation).

For the 0-50cm euc seedlings, maybe zero-inflated! How about the 2m high seedlings?

check_zeroinflation(glmer(euc_sdlgs.2m~NativePerennialGrass_cover+ExoticAnnualGrass_cover+ExoticPerennialGrass_cover+(1|Property), family = "poisson", data=euc))
# Check for zero-inflation

   Observed zeros: 341
  Predicted zeros: 326
            Ratio: 0.96
Model seems ok, ratio of observed and predicted zeros is within the
  tolerance range.

Looks like probably not.
