Download Data

The function fia_download() connects to FIA DataMart (FIADB), the official database of the Forest Inventory and Analysis (FIA) program. It downloads zip files of all CSVs and extracts only those specified using the “extract” argument. The function has the following arguments:

  • “states” allows you to indicate your state of interest. You can download any state in FIADB using the the two letter state abbreviation.
  • “download_dir” is used to indicate where the zip files should be saved. Default = “fia” to your desktop.
  • “extract” specifies which CSV files should be extracted from the state based on whether they are needed for “forestTIME” estimates, “rFIA” estimates, or “all”. Each CSV file for a state is a different table of data in FIADB.
  • “keep_zip” is a logical argument where you can indicate if you would like to keep the .zip file after it has beed extracted. The default = TRUE.

Here we will be downloading the state of New Hampshire. We choose NH due to its relatively small size and lighter computational load. I also specify extract = “rFIA” to compare population estimates from both methods later.

fia_download(
  states = "NH",
  download_dir = "../datasets/fia",
  extract = "rFIA",
  keep_zip = TRUE
)

Tidy data

The function fia_tidy() joins all columns needed into a single table. It also creates unique plot and tree identifiers using a concatenation of unit code, state code, county code, plot control number, and tree control number. This is an improvement to the current FIA database design, allowing repeated plot measurements to be connected longitudinally through time. This function also fills in missing values for ACTUALHT and HT to prepare for interpolation, overwrites species codes that appear to be in error, and fills in the mortality year (“MORTYR”) attributes so that every tree has a year of mortality.

data <- fia_tidy(nh_data)

“Annualize” the data via linear interpolation

The fia_annualze() function takes the tidied data and converts it into annualized estimates by interpolating between observations. This creates a continous annual dataset that can be used for time-series analysis.

It happens in three steps which themselves are separate functions: - expand_data() addes empty rows for all years between inventories for each tree in the dataset. -interpolate_data() performs linear interpolation between observations. Attributes that change through time (e.g. diameter, height, etc) are interpolated while time-invariant columns (e.g. plot_ID, SPCD, etc) are held static. -adjust_mortality() adjusts the mortality history of the tree depending on whether the argument use_mortyr is set to TRUE or FALSE.

data_midpoint <- fia_annualize(data, use_mortyr = FALSE)

Population Scaling

The forestTIME package includes a vignette on how to move from tree-level estimates to state-level estimates. Here we will be working through those steps.

Create domain indicator

In order to identify which trees meet the qualifications for remaining in the sample we need to create domain indicators. These are 0 or 1 values that get multiplied by the tree and plot estimates. Below we specify that we want base intensity plots on forested land and live trees.

data_midpoint_carbon <-
  data_midpoint_carbon |>
  mutate(
    aDI = if_else(COND_STATUS_CD == 1 & INTENSITY == 1, 1, 0), #forested land, base intensity plots
    tDI = if_else(STATUSCD == 1, 1, 0) * aDI #live trees on forested land
  )

Create expansion factor

The function fia_calc_expns() alows us to calculate state specific expansion factors by dividing total state area by number of plots (in a given year).

Note: This step may change in the future as we explore the use of evaluation ids.

data_midpoint_carbon <- data_midpoint_carbon |> fia_calc_expns()

Calculate tree totals

This step aggregates tree‑level carbon estimates up to the plot level. For each plot and year, it sums aboveground carbon (CARBON_AG) adjusted by the trees‑per‑acre factor (TPA_UNADJ), the expansion factor (EXPNS), and the domain indicator (tDI) to include only live trees on forested land. The result, converted from pounds to tons, gives the total carbon stock per plot (carbPlot) for that year.

tree_totals <- data_midpoint_carbon |>
  group_by(plot_ID, YEAR) |>
  summarize(
    carbPlot = sum(CARBON_AG * TPA_UNADJ * EXPNS * tDI / 2000, na.rm = TRUE), #tons/plot
  )
`summarise()` has grouped output by 'plot_ID'. You can override using the
`.groups` argument.

Calculate area totals

This step calculates the total forested area represented by each plot in each year. It groups the data by plot and year, ensures only one record per condition using distinct(), and then sums the proportion of forested land (CONDPROP_UNADJ) multiplied by the expansion factor (EXPNS) and the domain indicator (aDI). The result, forArea, gives the number of acres of forested land per plot for that year.

area_totals <- data_midpoint_carbon |>
  group_by(plot_ID, YEAR) |>
  # Keep only one row for each condition in each plot and year
  distinct(CONDID, COND_STATUS_CD, CONDPROP_UNADJ, EXPNS, aDI) |>
  summarize(
    forArea = sum(CONDPROP_UNADJ * EXPNS * aDI, na.rm = TRUE) #acres/plot
  )
`summarise()` has grouped output by 'plot_ID'. You can override using the
`.groups` argument.

Calculate state totals

This step combines plot‑level carbon and area totals to produce statewide estimates. By joining the tree and area tables, grouping by year, and summing across plots, it calculates the total aboveground carbon and total forested area. Dividing carbon by area yields carbon density (tons/acre), providing a population‑level measure of forest carbon storage for each year.

agc_pop <- inner_join(tree_totals, area_totals) |> 
  group_by(YEAR) |> 
  summarize(
    CARB_AG_TOTAL = sum(carbPlot, na.rm = TRUE),
    AREA_TOTAL = sum(forArea, na.rm = TRUE)
  ) |>
  mutate(method = "forestTIME-midpoint", carbon_ton_acre = CARB_AG_TOTAL / AREA_TOTAL) |>
  select(method, YEAR, carbon_ton_acre, carbon_total = CARB_AG_TOTAL, AREA_TOTAL)

Plot Carbon Density

This section visualizes statewide carbon density over time. By plotting tons of carbon per acre against year, we can see how live forest carbon stocks in New Hampshire have changed between 2002 and 2024.

agc_pop |>
  filter(YEAR >2000) |>
  ggplot(aes(x = YEAR, y = carbon_ton_acre)) +
  geom_line(color = "red") +
  labs(title = "Change in carbon density",
       subtitle = "New Hampshire 2002-2024",
       y = "Carbon (tons/acre)",
       x = "Year") +
  theme_bw()

Compare with rFIA

The vignette compares forestTIME estimates to those produced by the rFIA package. Both annual and temporally‑invariant (TI) approaches are calculated using the rFIA biomass() function, then combined with forestTIME results. Plotting them together highlights differences between estimation methods.

rfia_NH <- readFIA( dir = "../datasets/fia", states = "NH")

agc_rfia_annual <-
  biomass(
    rfia_NH,
    totals = TRUE,
    method = "annual",
    treeType = "live",
    landType = 'forest',
    component = "AG",
    areaDomain = COND_STATUS_CD == 1 & INTENSITY == 1
  ) |>
  mutate(method = "rFIA annual") |>
  select(method, YEAR, carbon_ton_acre = CARB_ACRE, carbon_total = CARB_TOTAL)
